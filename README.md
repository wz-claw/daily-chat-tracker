# 每日聊天统计

记录每日聊天时长，区分线上/线下。

## 使用方法

1. 更新 `data.json` 中的数据
2. 推送到 `gh-pages` 分支触发自动部署
3. 访问 GitHub Pages 查看统计

## 数据格式

```json
{
  "date": "YYYY-MM-DD",
  "online": 4,
  "offline": 1,
  "note": "💬"
}
```

- `online` - 线上聊天时长（小时）
- `offline` - 线下聊天时长（小时）
- `note` - 备注（可选），如 emoji 标记

## 统计页面

- 记录天数 / 总时长 / 线上时长 / 线下时长 / 日均时长
- 支持按过去 N 天筛选统计和趋势图
- 可开关趋势图上的 emoji 标注
- 堆叠柱状图趋势
- 详细数据表格
